# Umar Faruk J. — Portfolio

Personal portfolio website built with HTML, CSS and JavaScript.

## Structure

- `index.html` — main portfolio page
- `assets/css/` — stylesheet
- `assets/js/` — JavaScript
- `assets/images/profile/` — profile images
- `assets/images/projects/` — project images
- `assets/images/favicon.svg` — favicon
- `assets/documents/` — resume PDF
- `.vscode/` — VS Code launch configuration

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Deploy

This is a static website and can be deployed directly from GitHub to Vercel. No build command or output directory is required.
